How it works

Pick a meal type (Breakfast / Lunch / All Day), set a budget and choose Veg / Nonveg / All. Cafelytics computes a small set of diverse combos (pure veg, pure non-veg or mixed) that fit your budget and tastes. Order straight from a combo or customize using the full menu.

Quick tips
  • Choose All to see both vegetarian & non-vegetarian combos.
  • Increase Maximum Items to allow larger combos (3–6 items).
  • If you get no combos, try a higher budget or set meal type to None.
Pro tip

Want fewer choices? Lower candidate_top in the model pipeline to focus on top-ranked items only.
